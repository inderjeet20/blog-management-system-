# Screenshots Directory

This folder contains visual demonstrations of the Blog Management System.

## Screenshots Included

1. **01-homepage-filters.png** - Homepage showing blog listing with sidebar filters (Search, Category, Date Sorting, Date Range)
2. **02-blog-detail.png** - Individual blog detail page with full content
3. **03-admin-login.png** - Admin login page (Username: admin, Password: password)
4. **04-admin-dashboard.png** - Admin dashboard showing blog management table
5. **05-add-blog-form.png** - Add new blog form with title, category, description, content, and image upload

## How These Screenshots Were Generated

All screenshots were captured from the live application running on:
- **Frontend**: http://localhost:8000/
- **Admin Panel**: http://localhost:8000/admin/

The images showcase:
- ✅ Clean, modern UI design
- ✅ Responsive layout
- ✅ AJAX filtering in action
- ✅ Admin authentication flow
- ✅ Full blog management workflow

## Using Screenshots in README

The README.md references these images using relative paths:
```markdown
![Description](screenshots/01-homepage-filters.png)
```

When you push to GitHub or deploy online, these images will be automatically displayed in your README on the GitHub page.
